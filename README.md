# 🎓 Лицей 554 — Система распределения по профильным классам

Веб-приложение для автоматизации распределения учащихся по профильным классам (Физико-математический / Химико-биологический) на основе успеваемости и рекомендаций учителей.

## ✨ Возможности

### 🏫 Для администратора
- Управление учебными годами (создание, активация, удаление)
- Импорт данных учащихся из Excel-файлов
- Автоматическое создание предметов и классов из файла
- Просмотр успеваемости и рекомендаций по каждому ученику
- Экспорт отчетов в Excel (4 формата)
- Пересчет рекомендаций для всех учеников

### 👨‍🏫 Для преподавателя
- Просмотр списка учеников с фильтрацией по году, классу и профилю
- Выставление рекомендаций (0–10 баллов) по профильным предметам
- Массовое сохранение рекомендаций
- Просмотр текущих рекомендаций и итоговых результатов

### 🧠 Логика распределения
- **Минимальный балл для профиля — 6** (ниже 5 — не подходит)
- Поддержка нескольких подходящих профилей одновременно
- Подробная диагностика причин решения
- Кэширование результатов в Redis

## 🚀 Установка и запуск

### Требования
- Docker Desktop (Windows/Mac) или Docker + Docker Compose (Linux)
- Git
- 4 ГБ ОЗУ (рекомендуется)

### 1. Клонирование репозитория

```bash
git clone https://github.com/ghost00051/554
cd school-profile-system
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта:

```env
# Сервер
PORT=____
NODE_ENV=____

# База данных
DB_HOST=____
DB_PORT=____
DB_NAME=____
DB_USER=____
DB_PASSWORD=____

# Redis
REDIS_HOST=____
REDIS_PORT=____

# Файлы
MAX_FILE_SIZE=____
```

### 3. Запуск через Docker Compose

```bash
# Запуск всех сервисов
docker-compose up -d

# Просмотр логов
docker-compose logs -f app

# Остановка
docker-compose down

# Перезапуск с пересборкой
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```

### 4. Проверка работоспособности

```bash
# Health check
curl http://localhost:_____/api/health

# Должен вернуться ответ:
# {"status":"OK","timestamp":"2026-04-21T..."}
```

## 📡 API Endpoints

### 📚 Учебные годы

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/years` | Получить все годы |
| `POST` | `/api/years` | Создать год (`{year: "2025-2026"}`) |
| `PUT` | `/api/years/:id/active` | Активировать год |
| `DELETE` | `/api/years/:id` | Удалить год |
| `GET` | `/api/years/:id/classes` | Получить классы года |

### 👨‍🎓 Студенты

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/students` | Список студентов (фильтры: `academicYearId`, `classId`, `page`, `limit`) |
| `GET` | `/api/students/:id` | Студент с оценками и рекомендацией |

### 📊 Рекомендации

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/recommendations/student/:id` | Финальная рекомендация |
| `POST` | `/api/recommendations/student/:id/calculate` | Пересчитать для студента |
| `POST` | `/api/recommendations/calculate-all` | Массовый пересчет |
| `GET` | `/api/recommendations/year/:yearId` | Рекомендации по году |

### 👨‍🏫 Рекомендации учителей

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/recommendations/teacher/student/:id` | Все рекомендации студента |
| `POST` | `/api/recommendations/teacher` | Создать одну |
| `POST` | `/api/recommendations/teacher/batch` | Массовое создание |
| `PUT` | `/api/recommendations/teacher/:id` | Обновить |
| `DELETE` | `/api/recommendations/teacher/:id` | Удалить |

### 📁 Импорт/Экспорт

| Метод | URL | Описание |
|-------|-----|----------|
| `POST` | `/api/import/students` | Импорт Excel |
| `GET` | `/api/import/export/full-report` | Полный отчет |
| `GET` | `/api/import/export/students-only` | Только список |
| `GET` | `/api/import/export/recommendations-only` | Только рекомендации |
| `GET` | `/api/import/export/recommendations` | Старый формат |

### 🗂 Профили

| Метод | URL | Описание |
|-------|-----|----------|
| `GET` | `/api/profiles` | Все профили |
| `GET` | `/api/profiles/:id` | Профиль по ID |

| `POST` | `/api/profiles/:id/subjects` | Добавить предмет |

## 🗄 Структура базы данных

```sql
-- Основные таблицы
academic_years      -- учебные годы
classes             -- классы (связь с годом)
students            -- ученики (связь с классом и годом)
subjects            -- предметы (связь с годом)

-- Оценки и рекомендации
grades              -- оценки учеников
teacher_recommendations -- рекомендации учителей (0-10)
final_recommendations   -- итоговые рекомендации (JSONB)

-- Профили и настройки
profiles            -- профили (Физмат, Хим-Био)
profile_subjects    -- предметы профиля (с min_score)
```

## 📥 Импорт данных из Excel

### Формат файла (пример)

| A | B | C | D | E |
|---|---|---|---|---|
| **2025-2026** | | | | |
| **7 а класс** | | | | |
| **Обучающийся** | **Алгебра** | **Физика** | **Биология** | **Химия** |
| Иванов Иван | 4.5 | 4.8 | 5.0 | 4.2 |
| Петрова Анна | 3.8 | 4.2 | 4.5 | 3.9 |

### Требования
1. **Ячейка A1** — учебный год (формат `YYYY-YYYY`)
2. **Ячейка A2** — название класса (например `7 а класс`)
3. **Строка 3** — заголовки: `Обучающийся`, названия предметов
4. **Оценки** — числа (можно с точкой, через пробел будет обработано)

## 🧪 Тестирование

### Примеры запросов

```bash
# 1. Создать учебный год
curl -X POST http://localhost:_____/api/years \
  -H "Content-Type: application/json" \
  -d '{"year": "2026-2027"}'

# 2. Получить список студентов
curl "http://localhost:_____/api/students?academicYearId=1&limit=10"

# 3. Массовое создание рекомендаций
curl -X POST http://localhost:_____/api/recommendations/teacher/batch \
  -H "Content-Type: application/json" \
  -d '{"recommendations": [
    {"studentId": 1, "subjectId": 7, "score": 8}
  ]}'

# 4. Экспорт полного отчета
curl -o report.xlsx "http://localhost:_____/api/import/export/full-report?academicYearId=1"
```

## 🔧 Устранение неполадок

### Ошибка 413 (Payload Too Large)

```javascript
// В src/app.js увеличьте лимиты:
app.use(express.json({ limit: '50mb' }));
app.use(express.urlencoded({ extended: true, limit: '50mb' }));
```

### Ошибка 500 при создании профиля

```sql
-- Проверьте существование года
SELECT * FROM academic_years WHERE id = ваш_id;

-- Если нет — создайте:
INSERT INTO academic_years (year, is_active) VALUES ('2026-2027', true);
```

### Профили не возвращаются через API

```bash
# Очистите кэш Redis
docker exec -it school-redis redis-cli FLUSHALL

# Или перезапустите контейнеры
docker-compose restart
```

# Просмотр логов всех сервисов
docker-compose logs -f

# Только бэкенда
docker-compose logs -f app

# Только PostgreSQL
docker-compose logs -f postgres
